# Screenshots

Place your Invenio OS screenshots in this directory.

## Required Screenshots

| Filename | View to capture |
|---|---|
| `dashboard.png` | Main Dashboard — KPI cards and activity feed |
| `digital-twin.png` | Digital Twin — 3D view with workers active |
| `ai-assistant.png` | AI Assistant — response cards and quick actions |
| `mission-control.png` | Mission Control — task queue and dispatch |
| `inventory.png` | Inventory Registry — full item list with statuses |
| `alerts.png` | Alerts Panel — live feed with severity indicators |

## Tips

- Use a 1920×1080 or 1440×900 resolution for consistency.
- Capture with dark mode active (the default theme).
- Make sure the 3D simulation is running when capturing the Digital Twin.
- Crop to the main content area — no browser chrome needed.

## Adding to README

Once you have the screenshots, update `README.md` with:

```markdown
![Dashboard](docs/screenshots/dashboard.png)
![Digital Twin](docs/screenshots/digital-twin.png)
```
